# Analysis claim: differential expression

## Safe claim structure

`Within [cell type/group], [gene/pathway] was differentially expressed between
[conditions], using [test/model] with [multiple-testing control], suggesting
[bounded interpretation].`

## Required support

- Comparison groups and analysis population.
- Pseudobulk or model choice; if cell-level tests are used, disclose limits.
- Multiple-testing correction and effect size or rank.
- Direction, cell type, and dataset/cohort basis.

## Risk controls

- Do not treat cell count as donor replication.
- Avoid mechanism language from DEG lists alone.
- Separate gene-level findings from pathway/enrichment interpretation.
