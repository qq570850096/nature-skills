# Analysis claim: integration or batch effect

## Safe claim structure

`Integration reduced [batch/source] effects while preserving [biological
contrast], as assessed by [diagnostic evidence].`

## Required support

- Batch variables and biological variables.
- Integration method and key parameters.
- Evidence that biological signal remains interpretable.
- Pre/post integration diagnostics when making method-quality claims.

## Risk controls

- Do not use integration to erase disease, donor, or treatment signal.
- Do not claim cross-cohort generalization from a visually mixed UMAP alone.
- Report when analyses were run on raw, normalized, integrated, or pseudobulk
  representations.
