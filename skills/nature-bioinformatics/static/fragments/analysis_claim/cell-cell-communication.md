# Analysis claim: cell-cell communication

## Safe claim structure

`Ligand-receptor analysis nominated [source] to [target] signalling through
[pair/pathway], prioritizing [hypothesis] for validation.`

## Required support

- Method/database and database version if known.
- Source and target cell definitions.
- Expression evidence in both sender and receiver populations.
- Spatial co-localization or perturbation evidence for stronger claims.

## Risk controls

- Do not call predicted ligand-receptor pairs confirmed communication.
- Do not infer directionality beyond the method's assumptions.
- Report database dependence and false-positive risk.
