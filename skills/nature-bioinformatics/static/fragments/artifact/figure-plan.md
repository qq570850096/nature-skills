# Artifact: figure plan

## Output job

Plan figures as a sequence of scientific questions, not a gallery of standard
plots.

## Panel logic

- Start with cohort/sample and data-quality context when needed.
- Use one hero panel for the core biological finding.
- Pair embedding or spatial maps with quantification across samples.
- Add validation, sensitivity, or orthogonal evidence near the claim it supports.
- Avoid duplicate UMAPs or maps that answer the same question.

Open `references/figure-archetypes.md` for scRNA/spatial panel archetypes.
