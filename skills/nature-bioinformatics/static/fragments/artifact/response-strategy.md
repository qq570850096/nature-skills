# Artifact: response strategy

## Output job

Turn reviewer concerns into a bioinformatics-specific response strategy before
drafting point-by-point prose.

## Response mapping

- Annotation concern -> add marker evidence, reference mapping, confusion table,
  or soften label.
- Batch/integration concern -> report covariates, pre/post diagnostics, or
  rerun sensitivity analysis.
- Statistical concern -> clarify biological replicate unit, pseudobulk/model,
  correction method, and effect size.
- Communication/spatial/trajectory overclaim -> soften causal language or add
  validation.
- Reproducibility concern -> add software versions, accession IDs, code, and
  parameter details.

Do not claim that an analysis was added unless the user provides it.
