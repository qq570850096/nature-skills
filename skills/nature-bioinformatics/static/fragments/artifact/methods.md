# Artifact: Methods

## Output job

Write or audit Methods so the analysis can be reproduced and reviewed.

## Minimum Methods fields

- Data source, accession if known, cohort/sample definitions.
- Software and package versions when supplied.
- Preprocessing and QC thresholds.
- Normalization, integration, clustering, annotation, and statistical tests.
- Reference atlas, gene set, ligand-receptor database, or pathway database.
- Multiple-testing correction and model covariates.
- Availability of code, processed data, and figure source data.

Open `references/methods-reporting-checklist.md` for a full audit.
