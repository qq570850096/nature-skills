# Repository and accession guide

Use this file for data/code availability and accession audits.

## Typical repositories

| Data type | Preferred access route |
|---|---|
| Raw sequencing reads | SRA, ENA, DDBJ, or controlled-access repository when required |
| Gene expression matrices | GEO, ArrayExpress, Zenodo, Figshare, Dryad, or institutional repository |
| Human controlled-access data | dbGaP, EGA, controlled institutional repository, or governed access committee |
| Proteomics | PRIDE or another ProteomeXchange member repository |
| Processed single-cell objects | GEO supplementary files, Zenodo/Figshare/Dryad, or project repository with DOI |
| Code | GitHub/GitLab plus archived release on Zenodo or equivalent when possible |

## Required fields

- Repository name.
- Accession, DOI, or persistent identifier.
- Dataset title or scope.
- Raw and processed data separation.
- Metadata files and cell/sample annotations.
- Code version, commit, release, or environment.
- Licence or access condition when known.

## Weak wording to flag

- "Data are available upon request" with no restriction reason.
- "Public databases were used" without database names, versions, or accessions.
- "Code will be provided" without repository or release plan.
- One accession that cannot plausibly contain all data supporting the figures.
