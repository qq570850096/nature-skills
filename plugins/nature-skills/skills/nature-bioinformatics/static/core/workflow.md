# Workflow

Run these eight steps for any bioinformatics publication task.

## 1. Identify axes and output need

Detect `data_modality`, `analysis_claim`, and `artifact` from the request. State
the selected values in one short line before producing the main output.

## 2. Build the terminology ledger

Before drafting, record canonical forms for cell types, genes, datasets, cohorts,
software, reference atlases, packages, metrics, abbreviations, and omics layers.
Use the shared terminology-ledger rules.

## 3. Build a claim/evidence/boundary table

For each claim, capture:

- claim text
- evidence type and tier
- dataset/cohort/sample basis
- statistic or figure support
- validation status
- boundary or missing input

## 4. Run modality checks

Apply the selected data-modality fragment. Surface missing QC, integration,
spatial, or multiomic details before writing polished prose.

## 5. Run claim-specific checks

Apply each selected analysis-claim fragment. Downgrade language when the
analysis supports association or inference rather than mechanism.

## 6. Produce the artifact

Use the selected artifact fragment to draft Results/Methods prose, build a
figure plan, audit review risk, draft response strategy, or assemble an
accession checklist.

## 7. Run the reviewer-risk pass

Check whether a skeptical reviewer could ask:

- Where are the biological replicates?
- Was batch correction overused or underreported?
- Are cell labels justified?
- Are statistics and multiple testing clear?
- Are causal, spatial, trajectory, or communication claims overextended?
- Can data and code reproduce the claim?

Open `references/reviewer-risk-rubric.md` for full audits.

## 8. Return usable output plus gaps

Return ready-to-use text or a concrete checklist together with missing inputs,
risk flags, and recommended next evidence. Do not bury unresolved issues.
