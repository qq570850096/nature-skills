# Analysis claim: cell annotation

## Safe claim structure

`Cluster/state [label] was annotated based on [marker genes/reference atlas],
with [supporting evidence] and [ambiguity/boundary].`

## Required support

- Canonical marker genes or feature set.
- Reference atlas or label-transfer method when used.
- Evidence for rare, transitional, or disease-associated cell states.
- Distinction between broad lineage labels and fine-grained states.

## Risk controls

- Do not rename clusters to fit a story without marker support.
- Flag ambiguous labels and mixed marker signatures.
- Avoid using a single marker as definitive evidence for a cell type.
