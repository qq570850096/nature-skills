# Artifact: data availability checklist

## Output job

Build a data/code traceability checklist for bioinformatics publication.

## Minimum checklist

- Raw sequencing data repository and accession.
- Processed matrices, metadata, cell annotations, embeddings, and spatial
  coordinates where applicable.
- Figure source data and analysis notebooks/scripts.
- Code repository, commit/release, environment file, and licence if known.
- Third-party data source, version, date accessed, and citation.
- Controlled-access route for human or sensitive data.

Open `references/repository-accession-guide.md` for repository choices and
identifier language.
